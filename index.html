三步，五分钟

DSH 插件三步装完；技能类的按各自卡片里的说明走。

1

确认环境

已经有 DeepSeek Harness 的 Web 版或桌面版，终端里输入 node -v 能出版本号就够了。

2

复制一条命令

DSH 插件每款一行命令，Web 版用 dsh plugin --profile web add 加包名，桌面版请在应用内的插件管理页填包名。技能类不装进 Harness，按卡片里写的装进技能目录。

3

重启并启用

完全退出 DSH Host 再重新打开，进插件页启用。运行中的进程还握着旧插件，不重启就看不到效果。

常见问题

装之前先把最常卡住的几个问题看一遍，能省掉不少来回。

大肥鱼是这圈插件里的一个角色名。dsh-pet 的官方介绍就写着「吃白饭的蓝色大肥鱼」，字面意义上它就是一只赖在 DeepSeek Harness 里不走的蓝色鱼尾少女。这个目录把相关的桌面伙伴收在一起，省得你自己翻仓库。

这一页现在有六种东西。标着 DeepSeek Harness 的是 DSH 插件，必须先跑起 Harness，离开 DSH 起不来；标着 Codex 桌面端的挂在 Codex 里，需要装好 Codex 并用 ChatGPT 账号登录，它读的是 Codex 的额度，和 DSH 互不相干；标着技能市场的是从 skillhub.cn 上架的技能包；标着 skills.sh 目录的是挂在 skills.sh 上的技能，那一页有安装量和现成的安装命令；标着技能仓库（GitHub）的是 GitHub 上的开源技能；标着独立工具的是不装进任何 Agent、自己单独跑的开源项目，比如 ComfyUI 和 Coqui TTS。后三种是给 Agent 用的技能包，不装进 Harness。

技能市场那几款在页面上点「下载 Zip 包安装」，解压后按包内说明放进你的技能目录。GitHub 上那两款一个用 npx skills add（需要 Node.js 18 以上），一个是 clone 仓库后跑仓库自带的安装脚本。具体命令都写在各自卡片的命令块里，照着粘就行。

多数情况下不用。小鲸鱼优先读你在「设置 → 账号与余额」里的登录态，没有登录态才回落到 DEEPSEEK_API_KEY。看额度那一类走的是只读接口，不会创建聊天，也不会调用模型。技能类大多只读公开页面或公开搜索，同样不用额外准备凭据。具体每款的要求都写在各自的卡片里。

能。同一宿主下的插件装在同一套 profile 里互不冲突，一个管桌宠，一个管余额。跨宿主的插件本来就跑在另一个进程里，更是各走各的。技能包也是各装各的目录，互不影响。

插件跑在 DSH 进程内，动画本身不吃 GPU，余额读数是 60 秒一次。大肥鱼还能单独缩小或者直接隐藏，右键菜单里就能关掉。需要安静的场合它不会自己跳出来。

先完全退出 DSH Host 再重开，运行中的进程还握着旧插件。最容易踩的坑是桌面端：桌面端读的是 desktop profile，命令行按设计拒绝碰它，必须在应用内的插件管理页安装。技能类装完一般要重启对应的 Agent 会话才认得。

DSH 插件用 dsh plugin --profile web remove 加包名卸载。小鲸鱼如果之前用 github: 方式装的，先 remove 掉同名包再重装 npm 版，不然两个会并存打架。Codex 侧的那款在 Windows 上重跑安装包里的卸载脚本，Mac 把应用拖进废纸篓并删掉登录启动项。技能包直接删掉对应目录即可。
